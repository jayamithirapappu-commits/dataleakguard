# DATALEAKGUARD
DataLeakGuard is an AI security layer that detects, masks, and prevents sensitive information from reaching AI models before processing.

## Problem Statement
Users frequently paste sensitive information—like passwords, API keys, and PII—into GenAI prompts. Current security tools use aggressive, rigid redaction that strips out all sensitive data. This breaks the prompt's utility (e.g., deleting a phone number from a resume or removing code snippets from a debugging request).

### Why We Chose This Problem
We chose DataLeakGuard because existing AI tools generally process the information users send them, but users may not realize when their prompts contain sensitive data. Instead of stopping people from using AI, our solution provides a security layer before the data reaches the AI.

## Solution
DataLeakGuard — a pre-LLM privacy and data-loss prevention layer.

### Key features
* 🔍 Detects sensitive information automatically.
* 🛡️ Protects it before it reaches the AI.
* 📊 Calculates risk based on the type of data detected.
* 🤖 Allows users to continue using AI with a sanitized prompt.
* ⚡ Works in real time, without requiring users to manually identify sensitive information.
* 🔐 Reduces accidental privacy breaches while keeping the AI workflow convenient.
  
### Innovation and Differentiation
* Pre-AI protection: Stops sensitive data before it reaches the LLM.
* 🧠 Intelligent detection: Identifies PII, credentials, financial information, and custom sensitive data.
* 📊 Dynamic risk scoring: Classifies leaks as Low, Medium, High, or Critical.
* 🔄 Automatic anonymization: Replaces sensitive information with safe placeholders while preserving the meaning of the prompt.
* 🤖 AI-compatible: The user can still get a useful AI response without exposing their actual data.
